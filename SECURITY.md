# Security Policy

## Supported Versions

AISdb is archived, and no version receives security updates or fixes.

| Version | Supported |
| ------- | --------- |
| all     | :x:       |

## Reporting a Vulnerability

The repository is read-only, so it accepts no issues, pull requests or security advisories, and no report will lead to a fix or a release. The dependency versions pinned in the `Cargo.lock` and `package-lock.json` files are those of the last update on 2026-10-25 and will not change. Review them before you deploy any part of AISdb.
